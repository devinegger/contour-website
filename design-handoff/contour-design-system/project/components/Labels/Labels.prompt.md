Eyebrows and badges are the system's small uppercase teal labels.

```jsx
<Eyebrow>What we do</Eyebrow>
<Badge>Baseline</Badge>
<Badge variant="solid">Included</Badge>
```

`Eyebrow` is the kicker that sits above a heading. `Badge` defaults to a bare teal tier label (`text`); `variant="solid"` renders a low-opacity teal chip with 4px radius (set `onLight` on stone surfaces). Both use DM Sans 500, uppercase, 0.18em tracking. Never use pill shapes.
